# Ближайшие этапы

## Этап 1

- Установить Docker Desktop.
- Поднять PostgreSQL/pgvector через `docker compose up -d db`.
- Выполнить `python scripts/init_db.py`.
- Загрузить sample-документ `data/raw/fitness_contract_sample.md`.
- Задать первый вопрос через `python scripts/ask_cli.py`.

## Этап 2

- Подключить реальные локальные документы пользователя.
- Добавить договоры.
- Добавить правила клубов.
- Добавить переписки.
- Добавить претензии.

## Этап 3

- Подключить официальные источники законодательства РФ через разрешенные API или
  официальный экспорт.
- Не делать агрессивный scraping.
